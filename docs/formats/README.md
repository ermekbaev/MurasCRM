# Форматы ФНС

## УПД 5.03

`ON_NSCHFDOPPR_1_997_01_05_03_05.xsd` — официальная схема универсального
передаточного документа. Источник: сайт ФНС, приложение к приказу от 19.12.2023
№ ЕД-7-26/970@ в редакции приказа от 15.11.2024 № ЕД-7-26/1032@. Версия формата
5.03 применяется с I квартала 2026 года.

Схема лежит в репозитории намеренно: по ней проверяется то, что формирует
`src/lib/upd-xml.ts`. Печатная форма УПД для этого не годится — она показывает
состав полей, но не имена элементов, вложенность и обязательные атрибуты, а
оператор ЭДО отклоняет документ целиком при любом расхождении.

Проверить готовый файл:

    xmllint --noout --schema docs/formats/ON_NSCHFDOPPR_1_997_01_05_03_05.xsd файл.xml

Когда ФНС выпустит новую версию формата, схему нужно заменить и прогнать
проверку заново: имена элементов между версиями меняются.
